LeaveEase — Professional Leave Management System

Files
- index.html: Application structure and login screen
- style.css: Responsive professional styling
- script.js: Frontend interactions and leave calculations

Run
1. Extract the ZIP file.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. Enter any employee name to explore the demo.

Features
- Employee name/ID demo login
- Casual leave and medical leave balances
- Leave request form with date and balance validation
- Inclusive calendar-day calculation
- Overlapping request validation
- Pending request cancellation and balance restoration
- Overview dashboard, history filters, reason search, help modal
- Responsive desktop and mobile layouts

Important
This is a frontend-only demo. Login is not secure authentication. Requests are stored only in JavaScript memory and reset when the page is refreshed. There is no real administrator approval workflow, server, or database. Connect a secure backend and database before organizational use.
